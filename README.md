Offence IQ

Know the law. Apply the law. Think like a police officer.

Offence IQ is an interactive policing training platform designed to strengthen legislative knowledge, offence identification and operational decision-making through realistic scenarios, challenging assessments and detailed feedback.

Features

- Realistic policing scenarios
- Offence identification assessments
- Legislative knowledge testing
- Evidence evaluation
- Detailed assessment feedback
- Performance and progress tracking

Purpose

To help police officers develop confidence and competence in applying legislation and making informed operational decisions.

Development

Offence IQ is currently under development.
